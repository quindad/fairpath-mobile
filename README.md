# FairPath Mobile

FairPath is a native iOS and Android app built with Expo + React Native.

## Product direction
- Brand: FairPath
- Tagline: A FairPath Forward
- Supporting line: Opportunity Has a Path
- Primary accent: #A8F32C
- Platforms: iOS and Android
- Frontend: Expo + React Native + TypeScript
- Backend: Supabase
- AI: OpenAI-powered features through secure backend functions
